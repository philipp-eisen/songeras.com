# Single Player Mode Implementation Plan

## Overview

Add a "Solo Play" mode where a player plays alone with a lives system (3 lives, lose 1 per wrong placement). The game skips the lobby, removes tokens, and ends when lives = 0 or deck is exhausted.

## User Requirements

- **Lives system**: Start with 3 lives, lose one per wrong placement, game ends at 0 lives
- **Skip lobby**: Go directly into the game after selecting a playlist
- **No tokens**: Remove token UI and mechanics for solo mode
- **Entry point**: New "Solo Play" button on home page

## Implementation Steps

### 1. Schema Changes

**File: `convex/schema.ts`**

Add `'solo'` to game mode validator (line 14):

```typescript
const gameModeValidator = v.union(
  v.literal('hostOnly'),
  v.literal('sidecars'),
  v.literal('solo'),
)
```

Add solo-specific fields to `games` table (after line 147):

```typescript
// Solo mode fields
lives: v.optional(v.number()),           // Current lives remaining
startingLives: v.optional(v.number()),   // For displaying "2/3 lives"
finalScore: v.optional(v.number()),      // Timeline cards when game ends
```

### 2. Backend: Update Game Creation

**File: `convex/games.ts`**

Update `gameModeValidator` export (line 10-13) to include `'solo'`.

Update `create` mutation (line 82-177):

- Add `startingLives` arg (optional, default 3)
- For solo mode:
  - Set `useTokens: false`
  - Set `winCondition: 999` (effectively no win condition)
  - Set `lives` and `startingLives`
  - Auto-start the game (skip lobby phase)

Add helper function `startSoloGame()` that:

1. Gets the single player from `gamePlayers`
2. Fetches ready tracks from playlist
3. Shuffles and creates game cards
4. Deals 1 starting card to player's timeline
5. Sets up first round card
6. Updates game phase to `awaitingPlacement`

Update `gameResponseValidator` and `buildGameResponse` to include new fields.

### 3. Backend: Update Round Resolution

**File: `convex/turns.ts`**

Update `resolveRound` mutation (line 573+):

- Add `livesRemaining` and `gameOver` to return type
- For solo mode when placement is **incorrect**:
  - Decrement `game.lives` by 1
  - Discard the card (no betting system)
  - If lives = 0, set `phase: 'finished'` and record `finalScore`
- For solo mode, always keep `currentTurnSeatIndex: 0` (same player)
- Update game's `lives` field after each round

Add guards to token-related mutations to reject solo mode:

- `skipRound` - block for solo
- `placeBet` - block for solo
- `claimGuessToken` - block for solo
- `tradeTokensForCard` - block for solo
