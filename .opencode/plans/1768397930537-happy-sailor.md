# Original Plan: Switch Deployment to Cloudflare Workers

## Overview

Migrate from manual Nitro/Node.js deployment to Cloudflare Workers using Cloudflare's native Git integration:

- **Production**: Deploy to `cf.songeras.com` on `main` branch pushes
- **Preview**: Deploy to `*.preview.songeras.com` on other branches
- **Convex Preview Deployments**: Separate Convex backend per preview branch

## Cloudflare Workers Configuration

### Build Variables (Add in Cloudflare Dashboard)

| Variable                    | Value                 | Description                  |
| --------------------------- | --------------------- | ---------------------------- |
| `CONVEX_DEPLOY_KEY`         | (your production key) | Production Convex deploy key |
| `CONVEX_DEPLOY_KEY_PREVIEW` | (your preview key)    | Preview Convex deploy key    |

### Build Commands

| Setting                                  | Value                          |
| ---------------------------------------- | ------------------------------ |
| **Build command**                        | `pnpm run build:ci`            |
| **Deploy command**                       | `npx wrangler deploy`          |
| **Non-production branch deploy command** | `npx wrangler versions upload` |

### How It Works

The `scripts/build.sh` script detects the branch using Cloudflare's `CF_PAGES_BRANCH` environment variable:

- **main branch**: Uses `CONVEX_DEPLOY_KEY` to deploy to production Convex
- **other branches**: Uses `CONVEX_DEPLOY_KEY_PREVIEW` to create a preview Convex deployment

The Convex deploy command automatically sets `VITE_CONVEX_URL` before running the Vite build.

## Prerequisites (Your Actions)

### 1. Convex Setup

Go to: https://dashboard.convex.dev → Project Settings → Deploy Keys

- [ ] Generate a **Production Deploy Key**
- [ ] Generate a **Preview Deploy Key**

### 2. Cloudflare Worker Setup

In the Cloudflare Workers dashboard when connecting your repo:

- [ ] Set **Branch** to `main`
- [ ] Check **Builds for non-production branches**
- [ ] Set **Build command** to `pnpm run build:ci`
- [ ] Set **Deploy command** to `npx wrangler deploy`
- [ ] Set **Non-production branch deploy command** to `npx wrangler versions upload`
- [ ] Add **Build variables**:
  - `CONVEX_DEPLOY_KEY` = (your production key)
  - `CONVEX_DEPLOY_KEY_PREVIEW` = (your preview key)

### 3. (Optional) Default Convex Environment Variables

If your Convex functions need environment variables (like `SITE_URL`, API keys), set default values for preview deployments:

1. Go to Convex Dashboard → Project Settings
2. Scroll to "Default Environment Variables"
3. Add variables that preview deployments should inherit

## Notes

### Convex Preview Deployments

- **Isolated backends**: Each preview has its own database, functions, and config
- **Auto-cleanup**: Deleted after 5 days (14 days on Pro) or when replaced
- **Fresh data**: Preview backends start empty - use `--preview-run` if you need seed data

### Two Deploy Keys

- **Production Deploy Key**: Can only deploy to production. Used on `main`.
- **Preview Deploy Key**: Can create preview backends. Used on other branches.
